# UI artwork sources

`OwlGuide.png` was generated for this project on 2026-11-04 using the image generation tool. It is the available raster original. No editable layered illustration was supplied. Keep the original alpha channel when replacing it.

Prompt: a friendly small teal owl with a cream face and belly, amber wings and feet, navy eyes, one wing waving, on a closed coral mathematics book; rounded picture-book illustration with subtle paper texture, transparent background, no lettering.

`RoundedPanel.png` is generated by `Assets/UI/Editor/AdventureUIBuilder.cs`. Change `RoundedSprite()` to change its edge geometry, then remove only the generated RoundedPanel.png and its meta through the Unity Editor and rebuild shared assets. Reassign existing scene references if Unity gives the regenerated asset a new GUID. Prefer preserving its meta/GUID when updating it in an image editor.

Other icons displayed in the hub are existing project images in `Assets/Images/MainMenu/`. This work does not establish new licensing rights for those existing images.
